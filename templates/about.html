About WeatherApp

A simple weather application built as a college field project.

☁️
🐍

Python + Flask

The application uses Python with Flask to handle requests, connect to the weather service and render the webpages.

🌐

Weather API

Weather information is fetched dynamically from the OpenWeather API instead of being stored in a database.

🎨

HTML + CSS

The user interface is designed using HTML and CSS with a responsive, student-friendly layout.

Project Flow

User→Flask / Python→Weather API→Weather Data→Webpage

No database and no SQL are required because weather information is obtained dynamically from the API.
