WEATHERAPP - COLLEGE FIELD PROJECT

Technology:
- Python
- Flask
- HTML/CSS
- OpenWeather API
- No JavaScript
- No SQL
- No database

Pages:
1. Home
2. Current Weather
3. 5-Day Forecast
4. Hourly Forecast
5. Weather Details
6. Explore Cities
7. Weather Map
8. Favorite Cities
9. Weather Alerts
10. About

Run:
1. Open Terminal in this project folder.
2. Install dependencies: pip3 install -r requirements.txt
3. Start the app: python3 app.py
4. Open the local Flask address shown in Terminal.

Note:
The standard OpenWeather forecast endpoint supplies forecast points at 3-hour intervals. The Hourly Forecast page therefore displays the next 8 available forecast points.
